表改动原因类型

关键约束（第一个迁移脚本）

CREATE EXTENSION IF NOT EXISTS postgis;
CREATE EXTENSION IF NOT EXISTS btree_gist;
CREATE EXTENSION IF NOT EXISTS citext;

-- 同一台设备的有效占用不能重叠：并发下单的最后防线
ALTER TABLE device_block ADD COLUMN period tstzrange
  GENERATED ALWAYS AS (tstzrange(starts_at, ends_at, '[)')) STORED;
ALTER TABLE device_block ADD CONSTRAINT device_block_no_overlap
  EXCLUDE USING gist (device_id WITH =, period WITH &&)
  WHERE (released_at IS NULL);

-- 订单引用的方案必须属于同一个报价
ALTER TABLE quote_option ADD CONSTRAINT quote_option_quote_uq UNIQUE (quote_id, id);
ALTER TABLE delivery_order ADD CONSTRAINT order_option_fk
  FOREIGN KEY (quote_id, option_id) REFERENCES quote_option (quote_id, id);

-- 重试不会产生重复订单
ALTER TABLE delivery_order ADD CONSTRAINT order_idem_uq UNIQUE (user_id, idempotency_key);

枚举值

device_type   robot | drone
device.status active | offline | maintenance
weight_kg     0 < kg ≤ 10；无人机只接 ≤ 2 kg
价格          weight_kg × 英里 × $1
order.status  confirmed → dispatched → picked_up
              → in_transit → arrived → completed
              （终态另有 canceled、failed）
block.kind    order | return（charging、maintenance 后续预留）
actor_type    system | device | user | agent | operator
unavailable_reason  OVERWEIGHT | STEEP_TERRAIN
              | OUT_OF_RANGE | NO_DEVICE_AVAILABLE
              | DEADLINE_MISSED

约定：主键 uuid（事件表用 bigint 自增）；
时间 timestamptz，按 UTC 存；坐标 geography(Point, 4326)；
金额整数美分 *_cents。
后端用 Spring Data JPA + Hibernate Spatial；
schema 由 Flyway 迁移管理，不用 ddl-auto。
