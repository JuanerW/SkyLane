目录结构

skylane-fe/
├─ src/app/                     # Next.js App Router
│  ├─ (auth)/login/page.tsx            F · Sign In / Sign Up
│  ├─ (app)/layout.tsx                 AppShell + RequireAuth
│  ├─ (app)/ship/page.tsx              A · New Delivery
│  ├─ (app)/ship/plans/page.tsx        B · Compare Plans
│  ├─ (app)/orders/page.tsx            E · My Orders
│  ├─ (app)/orders/[id]/track/page.tsx D · Live Tracking
│  └─ (app)/account/page.tsx           Account Settings
├─ src/components/              # 按页面分文件夹，通用件放 ui/
│  ├─ ui/  shell/  ship/  plans/  checkout/
│  ├─ tracking/  orders/  account/  map/
├─ src/hooks/                   # 每个 hook 包一组接口
├─ src/lib/api.ts               # fetch 封装 + ApiError
├─ src/lib/sse.ts               # fetch + ReadableStream 读 SSE
├─ src/lib/photon.ts            # 地址补全
├─ src/lib/time.ts              # 统一按美西时间格式化
└─ src/types/api.ts             # 由后端 OpenAPI 生成
